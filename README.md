# 🇬🇧 English

## 📡 The Story Behind 5NN599

The name **5NN599** takes inspiration from amateur-radio culture and the RST signal-reporting system.

In Morse code (CW), **5NN** is a shortened way to send **599**. The letter `N` is used as a cut number for `9`, making the report quicker to transmit.

| RST | Meaning |
|:---:|:--|
| **R — 5** | Perfect readability |
| **S — 9** | Extremely strong signal |
| **T — 9** | Very pure CW tone |

The `T` part is used for CW tone reports; voice contacts normally use an `RS` report, such as `59`.

For me, it is also a reminder of what I value in engineering: **clarity, strength, and quality.**

# 🇰🇷 한국어

## 📡 5NN599의 의미

**5NN599**라는 이름은 아마추어 무선 문화와 RST 신호 보고 방식에서 영감을 얻었습니다.

모스 부호(CW) 교신에서 **5NN**은 **599**를 빠르게 전송하기 위한 축약 표기입니다. 숫자 `9`를 문자 `N`으로 줄여 보내는 컷 넘버(cut number) 방식입니다.

| RST | 의미 |
|:---:|:--|
| **R — 5** | 완벽하게 알아들을 수 있는 신호 |
| **S — 9** | 매우 강한 신호 |
| **T — 9** | 매우 깨끗하고 순수한 CW 음질 |

`T` 항목은 CW 교신에서 사용하는 음질 보고입니다. 음성 교신에서는 일반적으로 `59`처럼 RS 보고를 사용합니다.

저에게 5NN599는 개발에서도 중요하게 생각하는 **명확함, 성능, 품질**을 상징합니다.
